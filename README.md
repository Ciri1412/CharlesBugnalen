Charles Bugnalen - Personal Developer Portfolio

A modern, fully responsive personal developer portfolio built from scratch to showcase my technical skills, professional experience, academic background, and software development projects.

View Live Site: https://ciri1412.github.io/CharlesBugnalen/

Key Features

Dark & Light Mode: Custom theme toggle that saves the user's preference using browser localStorage.

Fully Responsive Design: Optimized for mobile, tablet, and desktop viewing with custom media queries and a mobile hamburger navigation menu.

Fluid Scroll Animations: Implemented IntersectionObserver in JavaScript to create smooth fade-in animations as elements enter the viewport.

Custom CSS Layouts: Utilizes modern CSS Grid and Flexbox for precise structural alignment (e.g., the interactive Experience timeline and Project cards).

Sticky Navigation: Transparent navigation bar that applies a glass-morphism blur effect upon scrolling.

Resume Integration: Direct download link to my latest professional CV.

🛠️ Technologies Used

This project was intentionally built without heavy frontend frameworks to demonstrate a strong command of core web fundamentals.

HTML5: Semantic markup and structuring.

CSS3: Custom styling, CSS Variables (for theme switching), Grid, Flexbox, and fluid animations.

Vanilla JavaScript: DOM manipulation, event listeners, and API integration (IntersectionObserver, localStorage).

Icons: Devicon for technology logos and inline SVGs for UI elements.

Project Structure

index.html - Landing page featuring a hero section and service offerings.

about.html - Detailed background, technical skills breakdown, and certifications.

experience.html - Reverse-chronological timeline of academic and professional history.

projects.html - Grid showcase of recent software development projects.

contact.html - Direct links to communication channels (GitHub, LinkedIn, Email, Messenger).

style.css - Global stylesheet containing all layout rules, variables, and responsive media queries.

script.js - Global scripts handling theme toggling, scroll animations, and mobile menu logic.

/src - Directory containing project assets (images, profile picture, gifs, and PDF resume).

Running Locally

To view this project locally, simply clone the repository and open the index.html file in any modern web browser. No local server, build tools, or package managers are required.

# Clone the repository
git clone https://github.com/Ciri1412/portfolio.git

# Navigate into the directory
cd portfolio

# Open index.html in your default browser
